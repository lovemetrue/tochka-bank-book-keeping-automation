# CLAUDE.md

Go-утилита (stdlib, без зависимостей): учёт и напоминания по УСН 6% для ИП через API Точка Банка. Общение с пользователем на русском.

## Файлы
- `main.go`: CLI `sync [--dry] | calc | remind`, клиент API, чтение/запись `income.jsonl`.
- `calc.go`: чистый расчёт авансов и взноса 1% (`Advances`, `ExtraContrib`). Покрыт `calc_test.go`.
- `config.json`: все законодательные значения, сроки, уплаченные взносы (`paid`). Менять только здесь.
- `ca.pem`: публичный корень Минцифры для `TOCHKA_CA`. `dotenv.py`: заглушка для `notify.py` на хосте.

## Правила
- `TOCHKA_JWT` никогда не печатать, не коммитить, не класть в логи. `.env`, `*.jsonl`, бинарник в `.gitignore`.
- Проверку TLS не отключать (`curl -k`, `InsecureSkipVerify` запрещены); только `TOCHKA_CA`.
- Деньги не отправлять автоматически: платёж только как черновик «на подпись», подтверждает человек в банке.
- Поступления из `review.jsonl` в доход автоматически не переносить, решает пользователь.
- Меняя расчёт, сначала тест в `calc_test.go` (`go test ./...`). Сроки/ставки по закону сверять с источниками из README, не по памяти.
- Минимализм: stdlib, один пакет, без лишних абстракций; упрощения с потолком помечать `// ponytail:`.

## Деплой
Продакшн: ВМ `root@85.198.81.59`, каталог `/opt/tochka-tax` (бинарник, `.env` 600, `config.json`, `ca.pem`, `dotenv.py`), cron 06:00 UTC. Собрать: `GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -o tochka-tax .`, скопировать бинарник. ВМ общая, чужие контейнеры не трогать.
